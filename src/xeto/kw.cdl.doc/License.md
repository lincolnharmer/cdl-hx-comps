# Overview

Two licenses apply to these libraries.

- **kW Engineering's work** is licensed under the Academic Free License version 3.0. The text is in `LICENSE` at the root of the repo.
- **Material from the Modelica Buildings Library** is redistributed under the MBL license, a revised 3-clause BSD license with an added paragraph on enhancements. That material is the class names, connector and parameter names, default values and short descriptions the specs carry. Each library's `NOTICE` file reproduces the MBL license.

The AFL does not change MBL's terms for the material reproduced from it.

# ASHRAE

The specs carry Clause 7 numbers and, where Clause 7 spells a class differently from MBL, its spelling. They carry no text from ANSI/ASHRAE Standard 231-2026 or Guideline 36.

# Project Haystack and Haxall

The libraries name Project Haystack point specs and `hx.comps` comps by qname. They copy no text from either. Project Haystack's Xeto libraries and Haxall are themselves licensed under the Academic Free License version 3.0.
